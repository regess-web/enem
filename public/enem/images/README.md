# Imagens do site ENEM

Coloque nesta pasta as imagens novas para substituir as imagens atuais do site.

## Arquivos sugeridos

- `hero-prof.jpg` — imagem principal da professora no topo do site (hero).
- `mockup-fisica.jpg` — imagem do Kit Premium na seção de planos.

## Como usar

1. Envie os arquivos para esta pasta pelo GitHub usando **Add file → Upload files**.
2. Mantenha os nomes acima para facilitar a substituição.
3. Depois de enviar, me avise para eu atualizar o HTML e fazer o site usar estas imagens locais.

**Dica:** prefira imagens comprimidas em WebP ou JPG, com boa qualidade e tamanho de arquivo reduzido. Se usar outros nomes ou formatos, me diga quais foram.
